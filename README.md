# Конфигурация Купорос

Цель: Управление задачами и активами ИТ
Аналог: Управление ИТ-отделом (https://softonit.ru/catalog/products/it/)

Работает только на средах Windows (в Linux интеграционные механизмы работать не будут)

Подсистемы:
- Учет задач пользователей
- Учет конфигураций
- ИТ-активы
- Телеграм
- Точки интеграции (см. https://github.com/Kyrales/archiC4_1C)
- StoryMap
- Управление сетью

## Учет задач пользователей
Полноценный Service-Desk для учета простых задач без согласований. Есть возможность формировать акты выполненных работ.
Возможность расширенного ведения учета рабочего времени

Задачи "Задачи пользователя" используются для фиксации в системе рабочих поручений либо персональных заданий пользователем программы (автором) и передачи ее для исполнения другому пользователю программы (исполнителю). В задаче указывается срок исполнения и приводится ее описание, выбираются согласователи.

## Учет конфигураций
Контроль обновления сложных конфигураций

## ИТ-активы
Простой учет активов без использования документов

## Телеграм
Конструктор ботов телеграмм с преднастройкой

## Точки интеграции
Все детали о подсистеме отражены в рамках отдельного продукта-расширения https://github.com/Kyrales/archiC4_1C

## StoryMap
Ведение пользовательских историй на основе проектов

## Управление сетью
Автоматизация создания пользователей через веб-сервисы в разных базах с использованием расширения УправлениеДоступомПользователей.cfe
